# Мафія - Онлайн гра в реальному часі

Повнофункціональна гра Мафія, розроблена на Next.js 14+ з Supabase для реального часу та бази даних.

## 🎮 Особливості

- **Реальний час**: Синхронізація гри через Supabase Realtime
- **Безпека**: Row Level Security (RLS) для захисту даних
- **Ролі**: Мафія, Лікар, Комісар, Мешканець
- **Адаптивний дизайн**: Темна детективна тема з Tailwind CSS
- **Серверна логіка**: Безпечний розподіл ролей на сервері

## 🛠 Технологічний стек

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Realtime)
- **Icons**: Lucide React
- **Styling**: Tailwind CSS з темною темою

## 📋 Вимоги

- Node.js 18+
- npm або yarn
- Обліковий запис Supabase

## 🚀 Швидкий старт

### 1. Клонування та встановлення

```bash
git clone <repository-url>
cd mafia
npm install
```

### 2. Налаштування Supabase

1. Створіть новий проєкт в [Supabase Dashboard](https://supabase.com)
2. Отримайте URL та anon ключ з Settings > API
3. Створіть файл `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
```

### 3. Налаштування бази даних

Виконайте SQL скрипти в порядку:

1. **Створення таблиць**:
   ```bash
   # Виконайте в SQL Editor Supabase
   # Вміст файлу: schema.sql
   ```

2. **RLS політики**:
   ```bash
   # Виконайте в SQL Editor Supabase
   # Вміст файлу: rls-policies.sql
   ```

### 4. Запуск розробки

```bash
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000) у браузері.

## 🎯 Як грати

### Створення кімнати

1. Перейдіть на `/room/[room-id]`
2. Додайте гравців (мінімум 3 для початку)
3. Натисніть "Почати гру"

### Ігровий процес

- **Очікування**: Гравці приєднуються до кімнати
- **Ніч**: Спеціальні ролі виконують дії
  - 📍 **Мафія**: Обирає жертву для вбивства
  - 💉 **Лікар**: Лікує одного гравця
  - 🔍 **Комісар**: Перевіряє роль гравця
  - 👤 **Мешканець**: Спить
- **День**: Обговорення та голосування
- **Кінець**: Визначення переможців

## 🏗 Архітектура

### База даних

```
roles (ролі)
├── id, name, display_name, description
├── team (mafia/town), action_priority
└── is_active

rooms (кімнати)
├── id (UUID), status (waiting/night/day/ended)
├── winner_team, current_day
└── timestamps

players (гравці)
├── id (UUID), room_id, user_id
├── nickname, role_id, is_alive
├── is_host, slot_number, voted_for
└── timestamps

game_actions (дії гри)
├── id (UUID), room_id, actor_id, target_id
├── action_type, action_data (JSONB)
├── phase (night/day), day_number
└── timestamp
```

### Компоненти

- **Room.tsx**: Основний компонент кімнати з Realtime
- **Lobby.tsx**: Лобі для очікування гравців
- **GameCard.tsx**: Карточка гравця
- **ActionPanel.tsx**: Панель дій залежно від ролі

### API Routes

- `/api/game/start`: Розподіл ролей та початок гри
- Серверна валідація та безпечне призначення ролей

## 🔒 Безпека

### Row Level Security (RLS)

- **Гравці** бачать лише нікнейми та статус життя
- **Власні ролі** видимі лише поточному гравцю
- **Мафія** бачить інших мафію вночі
- **Ведучий** має розширені права в кімнаті

### Безпечний розподіл ролей

- Ролі призначаються виключно на сервері
- Перемішування та валідація на backend
- Запобігання маніпуляціям з клієнта

## 📝 Розподіл ролей

### Кількість гравців → Ролі

- **3-4 гравці**: 1 мафія, решта - місто
- **5-6 гравців**: 1 мафія, 1 лікар, решта - місто  
- **7-8 гравців**: 1 мафія, 1 лікар, 1 комісар, решта - місто
- **9+ гравців**: 2 мафії, 1 лікар, 1 комісар, решта - місто
